Interactive Performance Chart

Описание проекта

С помощью вайбкодинга создан интерактивный график в файле index.html.


График показывает четыре показателя:

Cost;
CPA;
ROI confirmed;
Conversions.

Для каждого показателя используется отдельный цвет и стиль линии. При наведении мыши на точку появляются дата и значения всех показателей.


Использованные технологии

HTML;
CSS;
SVG;
Python;
PyScript.

Как создавался проект

Сначала был изучен исходный GIF и изображение с заданием. Затем с помощью вайбкодинга была создана HTML-страница с графиком, стилями и интерактивностью.


После этого были проверены:

внешний вид графика;
цвета и линии;
работа подсказки;
отображение точек;
адаптивность страницы.

Запуск

Откройте файл index.html в браузере.


Также можно запустить локальный сервер:

python -m http.server 8000

Затем открыть:

http://127.0.0.1:8000/index.html
